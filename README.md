# Microsoft financial forecast dashboard

## overview
interactive Power BI dashboard analyzing Microsoft SEC income statements. 
built to showcase P&L dashboard and forecast 2027 net income.
visualizes variance across growth scenarios.

## skills
* **financial modeling:** dynamic forecasting, variance analysis, scenario planning.
* **Power BI & DAX:** custom measures, switch functions, interactive bookmarks.
* **data prep:** cleaned raw SEC filings using Python for relational modeling.

## interactive features
* **scenario forecasting:** revenue and opex growth sliders.
* **variance analysis:** waterfall chart bridging actuals to projected net income.
* **kpi tracking:** operating margin, gross margin, and opex ratio.

## how to use
download `.pbix` file.
open in Power BI Desktop.
use scenario buttons to change growth parameters.
view pdf export if Power BI is not installed.
